# ZealMod

[English version](../../README.md)

Открытая прошивка для спидкуберского таймера **Zeal Smart Timer** и программа,
которой её собирают.

Таймер остаётся таймером: ZealMod живёт рядом со стоковой прошивкой и
открывается долгим нажатием кнопки. Внутри — меню с обложками, игры, часы,
календарь, настройки. Список программ и оформление вы выбираете сами, а свои
программы и темы можно написать и поставить, ничего не пересобирая.

## Что нужно

* сам таймер и кабель USB **с проводами данных** (зарядный не подойдёт);
* Python 3.9 или новее;
* один раз: `pip install esptool pyserial`.

Больше ничего: ни компилятора, ни драйверов. Разъём таймера разведён на
нативный USB чипа ESP32-C3, компьютер видит его сам.

## Как поставить

```sh
git clone https://github.com/ARTEMIY-FCC/ZealMod zealmod
cd zealmod
python3 studio/zealmod.py studio
```

Откроется окно (страница в браузере, программа работает на вашем компьютере и
никуда ничего не отправляет). Дальше:

1. вверху справа появится порт таймера — зелёная точка значит «вижу»;
2. слева отметьте программы, которые хотите поставить, и перетащите в нужном
   порядке — так они и встанут в меню;
3. посередине выберите тему и вид меню, справа — назначение кнопок и язык
   прошивки (по умолчанию английский, как и сам интерфейс Studio);
4. **прошить таймер** — через полминуты часы перезагрузятся уже с ZealMod.

Кнопка **сохранить .gbl** отдаёт готовый образ файлом: им можно поделиться, а
поставит его любой той же программой (или `zealmod flash файл.gbl`).

Перед первой заливкой имеет смысл нажать **копия флеша** — полный дамп
заводского состояния на всякий случай. Вернуть завод можно и без него:
кнопка **вернуть заводскую**.

## Как пользоваться на часах

| действие | как |
| --- | --- |
| открыть ZealMod | держать верхнюю кнопку 1,5 с (настраивается) |
| листать меню | ◀ ▶ (одинаково во всех видах меню) |
| запустить | ▲ |
| выйти из программы | держать её кнопку выхода (написана в списке программ) |
| выйти в таймер | ▼ в меню |

Часы, рекорды и настройки переживают выключение — они лежат в отдельном
секторе флеша, а не в оперативке.

## Свои программы и темы

Формат `.zm` — это программа (игра, часы, что угодно), `.zt` — тема. Оба
обычные zip-архивы. Чтобы поставить чужую, просто перетащите файл в окно
Studio: она проверит, подходит ли программа к вашей версии ZealMod, покажет
размер и добавит в список.

Написать свою:

```sh
python3 studio/zealmod.py new app моя_игра   # заготовка на C
python3 studio/zealmod.py emu моя_игра       # посмотреть на компьютере
python3 studio/zealmod.py pack моя_игра      # собрать моя_игра.zm
```

Для этого уже нужен компилятор (`riscv64-elf-gcc`) и SDL2 для эмулятора —
но только автору программы. Тем, кто её ставит, ничего этого не нужно:
`.zm` везёт внутри готовый машинный код, а Studio сама размещает его в образе
и связывает с ядром.

Подробности: [module.md](module.md) — как устроена программа,
[api.md](../api.md) — полный справочник по вызовам (на английском),
[docs/theme.md](theme.md) — как устроена тема,
[docs/architecture.md](architecture.md) — как это всё работает внутри.

## Командная строка

```
zealmod devices          кто подключён по USB
zealmod build --all      собрать образ со всеми программами
zealmod flash [образ]    залить в часы
zealmod check игра.zm    подойдёт ли программа
zealmod pack каталог/    собрать .zm из исходников
zealmod new app|theme    заготовка
zealmod emu [каталог]    эмулятор на компьютере
zealmod backup           полная копия флеша
zealmod studio           окно
```

`--lang ru` переключает надписи прошивки на русский; у окна Studio свой
переключатель языка.

## Что внутри репозитория

```
work/        прошивка: ядро ZealMod и исходники встроенных программ
studio/      ZealMod Studio и zealmod — вся работа с образом на Python
modules/     список встроенных программ (builtin.json)
themes/      темы оформления, из них собираются .zt
examples/    заготовка своей программы
dist/        собранный комплект: ядро, модули, темы, стоковый образ
docs/        как это устроено
```

## Осторожно

* ZealMod переписывает раздел `ota_0` — то самое место, где лежит стоковая
  прошивка таймера. Заводскую всегда можно вернуть: она лежит в
  `dist/base/zeal-stock.gbl`, кнопка **вернуть заводскую** заливает её обратно.
* Studio проверяет, что стоковая прошивка в комплекте совпадает с той, под
  которую собран мод. Если у вашего таймера другая версия — она об этом
  скажет; лучше остановиться и сначала снять копию флеша.
* Мы правим чужую прошивку тремя четырёхбайтными перемычками. Это надёжно
  ровно настолько, насколько совпадает версия — см. `studio/zealmod/profiles/`.
